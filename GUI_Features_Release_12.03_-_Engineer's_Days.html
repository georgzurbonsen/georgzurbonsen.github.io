Overview

Release 12.03, issued 2026-09-14, "Engineer's Days"
In various countries of the world, Engineer's Days are celebrated. In Romania and South Africa, it's on the 14. September, India follows 15. Sept, Canada on 17. Sept., Turkey on 19. Sept. Switzerland: 4. March, USA: Last week of February.

Bugfixes

  • table lookup() function family: Error messages have confused the 2nd with 5th parameter, as well as 3rd with 6th Parameter.
  • table lookup() function family: Corrected a bug in Changed Counter.
  • table row width() crashed with error message when attempting to check an empty table or a row beyond end of the table. Now, -1 is returned.

New Functions

  • table digest once() function family: Every row in the lookup table can only be looked up once.
  • table expand once() function family: Same here.

Improvements in Existing Functions

  • table load excel file(): Enabled accepting exports from additional online databases where the Excel contents deviate from the conventions used by Excel.
  • table load excel file(): In addition: it is now able to load empty tables without complaining.
